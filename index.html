Send to WattOdds

Download a project file, then use Import project file in WattOdds. The loss items keep their values and how they were set.

Method. Net energy is gross × Π(1 − Lᵢ): each loss is a share of the energy left after the ones before it, so the order changes each step's GWh but not the total. Loss uncertainty follows WattOdds: each item adds (sᵢ/ηᵢ)² to the variance, with ηᵢ = 1 − Lᵢ, items are independent, and year-to-year variability adds (iavᵢ/ηᵢ)²/N over an N-year average. Module degradation is a yearly rate: over N years the average loss is rate × (N − 1)/2.

Storage is LossStack's own step. Only the stored share f pays round-trip and auxiliary losses: L = f × (100 − RTE) and L = f × aux, with σ scaled by f. WattOdds simulates storage hour by hour, so the project file passes on generation before storage and the battery values as WattOdds' battery items. Item names, options, defaults and sources come from WattOdds (). A screening tool: it does not replace an independent energy yield assessment.
